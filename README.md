# dataverse-migration-tool

A Power Platform Code App for migrating Dataverse data and solution components between Power Platform environments. The tool is intended to support secure, resumable migrations; incremental and full migration modes; validation reports; and rollback guidance for enterprise and government-ready deployments.

## Intended stack

Power Platform Code Apps, PCF, Dataverse Web API, `pac` CLI, .NET 9, C#, TypeScript, React, Fluent UI, and GitHub Actions.

## Product vision and architecture

See [Product Vision and Architecture Overview](docs/product-vision.md) for the migration goals, clean-architecture boundary, named subsystems, and enterprise/government readiness principles.

Early scaffolding. This repository is public open source and will be expanded as the project takes shape.
