## What each guide covers

| Guide | Purpose |
| --- | --- |
| Installation guide | Prerequisites, workstation setup, and enterprise or government deployment considerations |
| Configuration guide | Environment, identity, connectivity, and logging configuration |
| Migration runbook | Preflight, execution, validation, resume, and operator checkpoints |
| Troubleshooting guide | Common failures, diagnostics, and recovery paths |
| Rollback guide | Containment, restore, replay, and sign-off steps |
| Contribution guide | Coding standards, Definition of Ready, and Definition of Done |
| Architecture reference | Major components, data flow, and trust boundaries |
| API reference | External dependencies and planned internal contracts |
